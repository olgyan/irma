# irma - набор скриптов для обработки текстовых файлов ИРБИС64 перед импортом в БД и других библиотечных дел

airing.py - калькулятор изменения влажности воздуха после проветривания

batch_open_urls.py - массовое открытие URL, выгруженных списком в текстовый файл

els_scraper.py - проверка, не пропали ли из прописки издания в ЭБС Лань, Айбукс и Znanium

files_together.py - "склеивание" текстовых файлов Ирбис, чтобы импортировать их все разом

get_text.py - вспомогательный модуль для прочтения и записи текстовых файлов

marc_to_irbis.py - конвертер записей MARC в Ирбис, если родной конвертер Ирбиса не сработал

remove_fields.py - удаление ненужных полей из записей текстового файла, чтобы уменьшить файл и ускорить импорт

select_records.py - вспомогательный модуль для отбора записей, содержащих некий текст

sorting.py - сортировка полей в каждой записи по возрастанию (для сравнения текстовых файлов)

tidy.py - очищение записей, экспортированных из ЭБС Айбукс

txt_management.py - разное
